# 카봇 모닝 · Carbot Morning

헬로 카봇 테마의 아침 준비 대시보드(단일 HTML). GitHub Pages로 제공됩니다.

- 주소: https://elleyoonna-cmd.github.io/carbot-morning/
- `main` — 원본 소스 브랜치
- `gh-pages` — GitHub Pages가 실제로 서빙하는 브랜치 (같은 내용)
- `index.html` — 앱 전체(이미지·스크립트 내장), `.nojekyll` — Jekyll 처리 없이 서빙

수정 후 배포: `sh work/hello-carbot-dashboard/deploy.sh` (빌드 → main/gh-pages 동시 푸시)

검색 노출 방지를 위해 `noindex, nofollow` 메타 태그가 들어 있습니다.
